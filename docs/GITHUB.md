# GitHub

Repositório de destino:

`akillibrasil-dev/diversoes-veneza-ingressos`

Branch principal: `main`.

O código está preparado em um repositório Git local. A conexão GitHub disponível nesta sessão permite operar repositórios existentes, mas não expõe a criação de um repositório novo. Assim que o remoto vazio existir em `akillibrasil-dev`, basta adicionar `origin`, publicar `main` e conectar o projeto Vercel ao repositório para habilitar CI/CD por push.

Não versionar `.env.local`, tokens OAuth, chaves de serviço ou segredos de webhook.
